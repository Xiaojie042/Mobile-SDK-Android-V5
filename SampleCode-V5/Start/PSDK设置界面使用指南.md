# PSDK 设置界面使用指南

## 概述

PSDK（Payload SDK）设置界面是一个用于管理和监控 DJI 飞行器上 Payload 设备的界面。该界面位于默认演示界面的设置菜单中，与遥控器设置、图传设置、云台设置等处于同一级别。

## 界面位置

1. 启动应用程序
2. 进入默认演示界面（Default Layout）
3. 点击设置按钮（通常在右上角）
4. 在设置菜单中找到 "Payload 设置" 选项卡
5. 该选项卡位于云台设置之后

## 界面功能

### 1. PSDK 挂载点选择

界面顶部提供了两排RadioButton布局，用于选择要连接的PSDK挂载点：

**第一排**：
- **上方挂载点**: 飞行器顶部的PSDK接口
- **左侧挂载点**: 飞行器左侧的PSDK接口  
- **右侧挂载点**: 飞行器右侧的PSDK接口

**第二排**：
- **扩展点1**: 预留扩展挂载点
- **扩展点2**: 预留扩展挂载点
- **扩展点3**: 预留扩展挂载点

**界面特点**：
- 采用12sp小字体，节省空间
- 两排布局，无需滑动操作
- 单选模式，默认选择上方挂载点

### 2. 设备信息显示

实时显示当前选中挂载点的PSDK设备信息：
- 设备名称
- 设备类型
- 序列号
- 固件版本
- 连接状态
- 上传带宽

### 3. 网络设置

配置数据转发的目标服务器：
- **服务器IP**: 默认192.168.3.31，可修改
- **端口**: 默认8888，可修改
- **连接按钮**: 绿色文字，用于连接服务器
- **断开按钮**: 红色文字，用于断开连接
- **连接状态**: 实时显示网络连接状态

**按钮颜色说明**：
- 连接按钮：绿色文字(#00AA00)，表示安全操作
- 断开按钮：红色文字(#FF4444)，表示停止操作

### 4. 实时数据显示

一个滚动文本框，显示两类数据：

**系统日志**：
- 操作记录和状态信息
- 网络连接状态变化
- 挂载点切换记录

**PSDK数据**：
- 从PSDK设备接收到的原始数据
- 带时间戳的数据记录
- 自动转发状态信息

**消息格式**：
```
=== 系统日志 ===
[HH:mm:ss] 操作信息

=== PSDK 数据 ===
[HH:mm:ss] 接收到的数据内容
```

## 使用流程

### 基本操作流程

1. **选择挂载点**
   - 点击对应的RadioButton选择要监控的PSDK挂载点
   - 系统会自动切换监听器到新的挂载点
   - 消息区域会显示切换信息

2. **配置网络转发**
   - 输入PC端服务器的IP地址和端口
   - 点击绿色的"连接"按钮建立网络连接
   - 连接成功后状态显示为"已连接"

3. **监控数据**
   - 界面会实时显示PSDK设备信息
   - 接收到的PSDK数据会自动显示在消息区域
   - 如果网络已连接，数据会自动转发到PC端

4. **数据管理**
   - 点击"清空消息"按钮清除历史数据
   - 点击红色的"断开"按钮停止网络转发

### 网络转发功能

**自动转发机制**：
- 接收到PSDK数据后自动构造JSON格式
- 包含时间戳、设备信息和原始数据
- 通过TCP连接转发到PC端服务器

**JSON数据格式**：
```json
{
  "type": "psdk_data",
  "timestamp": "2024-01-01 12:00:00",
  "payload_index": "UP",
  "device_name": "设备名称",
  "device_type": "设备类型",
  "serial_number": "序列号",
  "firmware_version": "固件版本",
  "is_connected": true,
  "data": "原始数据内容"
}
```

## 技术特性

### 多挂载点支持
- 支持UP、LEFT_OR_MAIN、RIGHT三个主要挂载点
- 预留扩展挂载点选项
- 动态切换监听器，无需重启应用

### 实时状态监控
- 网络连接状态实时更新
- PSDK设备连接状态监控
- 数据传输状态显示

### 内存管理
- 消息缓冲区有大小限制（5000字符）
- 自动清理过期数据，避免内存溢出

## 注意事项

### 网络配置
1. **网络要求**: 确保Android设备与PC在同一网络段
2. **防火墙**: 确认PC端防火墙允许对应端口的连接
3. **服务器**: PC端需要运行对应的TCP服务器程序

### 挂载点选择
1. **硬件对应**: 根据实际硬件连接选择正确的挂载点
2. **设备检测**: 如果选择的挂载点没有设备，会显示"暂无设备连接"
3. **动态切换**: 可以随时切换挂载点，无需断开网络连接

### 数据格式
1. **JSON格式**: 转发的数据为JSON格式，便于PC端解析
2. **编码格式**: 使用UTF-8编码，支持中文字符
3. **数据完整性**: 包含完整的设备信息和时间戳

## 故障排除

### 连接问题
**症状**: 点击连接按钮后无法连接服务器
**解决方案**:
1. 检查网络连接是否正常
2. 确认服务器IP和端口设置正确
3. 验证PC端服务器程序是否正在运行
4. 检查防火墙设置

### 数据接收问题
**症状**: 无法接收到PSDK数据
**解决方案**:
1. 确认PSDK设备已正确连接到飞行器
2. 检查挂载点选择是否与实际硬件对应
3. 查看系统日志获取详细错误信息
4. 尝试切换到其他挂载点测试

### 界面显示问题
**症状**: 按钮颜色不明显或文字看不清
**解决方案**:
1. 连接按钮应显示为绿色文字
2. 断开按钮应显示为红色文字
3. 如果颜色不明显，可能是主题或显示设置问题
