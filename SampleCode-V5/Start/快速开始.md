# PSDK 设置界面 - 快速开始

## 🚀 快速验证界面

### 步骤 1: 编译项目

```bash
cd android-sdk-v5-as
.\gradlew.bat :uxsdk:compileDebugJavaWithJavac
```

**编译状态**: ✅ 成功 - 所有编译错误已修复

### 步骤 2: 运行示例应用

1. 打开 Android Studio
2. 导入项目 `android-sdk-v5-as`
3. 连接 Android 设备或启动模拟器
4. 运行应用

### 步骤 3: 访问 PSDK 设置界面

1. 应用启动后，点击 **Default Layout** 按钮
2. 在主界面右上角找到 **设置图标** ⚙️
3. 点击进入设置菜单
4. 找到 **Payload 设置** 选项卡（在云台设置之后）
5. 点击进入 PSDK 设置界面

## 🎨 界面改进

### 视觉优化
- **背景颜色**: 改为浅灰色 (#F5F5F5) 提高可读性
- **文字颜色**: 使用深灰色 (#333333) 确保与背景对比度
- **输入框**: 白色背景，深色文字，清晰的提示文字
- **按钮**: 保持原有样式，添加白色文字确保可见性

### 交互改进
- **挂载点选择**: 从单选按钮改为列表视图
- **显示所有挂载点**: 自动显示所有可用的 PayloadIndexType
- **单选模式**: 列表支持单选，清晰显示当前选择
- **动态加载**: 自动获取所有可用挂载点，无需手动配置
