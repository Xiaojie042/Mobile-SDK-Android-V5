# DJI USB数据发送功能使用手册

## 📋 项目概述

本项目是基于DJI Android SDK开发的USB数据发送功能，支持通过USB协议和网络转发两种方式向外部设备发送数据。该功能已集成到DJI无人机应用的测试工具界面中。

### 🎯 主要功能
- **USB传输模式**: 支持BULK、CONTROL、INTERRUPT三种USB协议
- **网络转发模式**: 通过TCP网络将数据转发到PC端
- **实时状态监控**: 显示连接状态、发送进度和传输统计
- **发送历史记录**: 保存和显示数据发送历史

---

## 🔌 硬件连接方案

### 方案一：USB传输模式（连接外部USB设备）

```
DJI RC PLUS遥控器 (Android主机)
├── USB-A口: 连接目标USB设备（如Arduino、USB转串口模块等）
└── USB-C口: 连接到PC（用于调试，输出logcat日志）
```

**硬件要求：**
- DJI RC PLUS遥控器
- 目标USB设备（支持USB Host模式）
- USB数据线

### 方案二：网络转发模式（推荐）

```
DJI RC PLUS遥控器 (Android客户端)
├── USB-C口: 连接到PC（用于调试）
└── 通过WiFi网络与PC通信

PC端 (TCP服务器)
└── 运行Python数据接收脚本
```

**网络要求：**
- PC和DJI遥控器在同一局域网
- 网络端口8888可用
- 防火墙允许TCP连接

## 💻 软件操作指南

### 第一步：启动DJI应用

1. 在DJI遥控器上启动DJI无人机应用
2. 进入主界面 → 选择"测试工具"
3. 在测试工具列表中选择"USB Data Send"

### 第二步：选择传输模式

#### 模式1：网络转发模式（推荐）

1. **选择协议**: 在下拉菜单中选择"网络转发"
2. **连接服务器**: 点击"连接服务器"按钮
3. **验证连接**: 观察状态显示"网络连接: 已连接 - 服务器: [PC IP]:8888"
4. **发送数据**: 在数据输入框输入内容，点击"发送数据"

#### 模式2：USB传输模式

1. **选择协议**: 选择BULK、CONTROL或INTERRUPT协议
2. **扫描设备**: 点击"扫描USB设备"发现可用设备
3. **连接设备**: 从设备列表中选择目标设备
4. **发送数据**: 输入数据并点击"发送数据"

### 第三步：PC端数据接收

#### Python脚本运行方法：

```bash
# 进入项目目录
cd e:\DJI_MSDK\Mobile-SDK-Android-V5\SampleCode-V5\android-sdk-v5-sample

# 运行数据接收器
python pc_usb_data_receiver.py --host 192.168.3.31 --port 8888
```

#### 脚本参数说明：
- `--host`: PC本地IP地址（默认: 192.168.3.31）
- `--port`: 监听端口（默认: 8888）
- `--save`: 可选，保存数据到文件

## 🔧 技术架构

### Android端架构
```
USBSendDataFragment (界面层)
    ↓
USBSendDataVM (ViewModel层)
    ↓
USBDataRepository (数据层)
    ├── USB传输模块 (USB Host API)
    └── 网络客户端模块 (TCP Socket)
```

### 数据传输流程

#### 网络转发模式：
```
用户输入数据 → Android应用 → TCP客户端 → 网络 → PC Python脚本 → 数据接收
```

#### USB传输模式：
```
用户输入数据 → Android应用 → USB Host API → USB数据线 → 目标USB设备
```

## 📊 界面功能详解

### 主界面元素

1. **USB设备选择区域**
   - 设备下拉列表：显示发现的USB设备
   - 扫描按钮：重新扫描可用设备

2. **连接状态显示**
   - USB连接状态：未连接/已连接/连接中/错误
   - 网络连接状态：显示服务器地址和连接状态

3. **协议选择区域**
   - BULK传输：大数据量传输
   - 控制传输：设备配置传输
   - 中断传输：实时数据传输
   - 网络转发：通过网络发送到PC

4. **数据输入区域**
   - 多行文本输入框：支持文本、十六进制、二进制格式
   - 发送数据按钮：根据连接状态启用/禁用

5. **进度和历史区域**
   - 进度条：显示数据发送进度
   - 发送历史：记录所有发送操作

## 🔍 故障排除

### 常见问题及解决方案

#### 问题1：网络连接失败
**症状**: 客户端数量显示为0，无法建立连接
**解决方案**:
- 检查PC和遥控器是否在同一网络
- 验证防火墙设置，确保8888端口开放
- 确认PC IP地址正确

#### 问题2：USB设备无法识别
**症状**: 扫描不到USB设备
**解决方案**:
- 检查USB线缆连接
- 确认设备支持USB Host模式
- 检查Android权限设置

#### 问题3：发送数据按钮不显示
**症状**: 界面缺少发送数据按钮
**解决方案**:
- 上下滑动屏幕查看完整内容
- 检查布局是否超出屏幕范围

#### 问题4：数据发送失败
**症状**: PC端未收到数据
**解决方案**:
- 检查网络连接状态
- 验证Python脚本是否正常运行
- 查看Android logcat日志

## 📈 性能指标

### 网络转发模式
- **最大数据包大小**: 4KB
- **传输延迟**: < 100ms（局域网）
- **并发连接**: 支持多客户端
- **数据格式**: 原始字节流 + 换行符分隔

### USB传输模式
- **支持协议**: BULK、CONTROL、INTERRUPT
- **传输速率**: 取决于USB设备能力
- **超时设置**: 5秒

## 🔒 安全注意事项

### 网络安全
- 使用局域网内部通信，避免公网暴露
- 建议使用静态IP或DHCP保留地址
- 定期检查防火墙设置

### 数据安全
- 传输数据为明文，敏感数据请加密
- 建议在生产环境中使用TLS加密
- 定期清理发送历史记录
